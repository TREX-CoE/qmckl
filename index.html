QMCkl

Quantum Monte Carlo Kernel Library

v1.1.0 BSD 3-Clause C & Fortran 90 no JavaScript

The domain of quantum chemistry needs a library in which the main kernels of Quantum Monte Carlo (QMC) methods are implemented. QMCkl exposes the main algorithms in a simple language and provides a standard API and tests to enable the development of high-performance QMC implementations taking advantage of modern hardware.

Getting started

QMCkl is built with GNU Autotools. The C compiler is selected with CC, the Fortran compiler with FC; compiler options go in CFLAGS and FCFLAGS. Reading wave function data through TREXIO is enabled by default (--without-trexio to disable).
