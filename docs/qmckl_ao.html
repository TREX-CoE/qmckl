Atomic Orbitals

1. Introduction

The atomic basis set is defined as a list of shells. Each shell s is centered on a nucleus A, possesses a given angular momentum l and a radial function Rs. The radial function is a linear combination of primitive functions that can be of type Slater (p=1) or Gaussian (p=2):

Rs(𝐫)=𝒩s|𝐫−𝐑A|ns∑k=1Nprimaksfksexp(−γks|𝐫−𝐑A|p).

In the case of Gaussian functions, ns is always zero. The normalization factor 𝒩s ensures that all the functions of the shell are normalized (integrate) to unity. Usually, basis sets are given a combination of normalized primitives, so the normalization coefficients of the primitives, fks, need also to be provided.

Atomic orbitals (AOs) are defined as

χi(𝐫)=ℳiPη(i)(𝐫)Rθ(i)(𝐫)

where θ(i) returns the shell on which the AO is expanded, and η(i) denotes which angular function is chosen and P are the generating functions of the given angular momentum η(i). Here, the parameter ℳi is an extra parameter which allows the normalization of the different functions of the same shell to be different, as in GAMESS for example.

In this section we describe first how the basis set is stored in the context, and then we present the kernels used to compute the values, gradients and Laplacian of the atomic basis functions.

2.2.1. After initialization

When the basis set is completely entered, extra data structures may be computed to accelerate the calculations. The primitives within each contraction are sorted in ascending order of their exponents, such that as soon as a primitive is zero all the following functions vanish. Also, it is possible to compute a nuclear radius beyond which all the primitives are zero up to the numerical accuracy defined in the context.

2.2.2. HPC-specific data structures

With HAVE_HPC, the basis is rearranged by nucleus so that the radial part of each shell is a dot product over the primitives of its nucleus. The context stores:

  • prim_num_per_nucleus[inucl], the number of primitives of the nucleus once the duplicates are removed
  • Cpsa in coef_per_nucleus(iprim, ishell, inucl), the coefficient of the primitive p in the shell s of nucleus a
  • γpa in expo_per_nucleus(iprim, inucl), the exponent of the primitive p of nucleus a

The exponents of a nucleus are sorted in increasing order, so the loop over primitives stops at the first one whose γpar2 exceeds the cutoff. When two primitives of the same nucleus share an exponent, they are merged and their coefficients added.

For a Gaussian shell the radial part is then

Rsa(r)=∑pCpsaexp(−γpar2)

The exponentials are evaluated once per point and per nucleus, then reused by all the shells of that nucleus.

vi=exp(−ai|X−R|2)
∇xvi=−2ai(Xx−Rx)vi
∇yvi=−2ai(Xy−Ry)vi
∇zvi=−2ai(Xz−Rz)vi
Δvi=ai(4|X−R|2ai−6)vi

3.2. General functions for Slater basis functions

qmckl_ao_slater_vgl computes the values, gradients and Laplacians at a given point of n Slater-type orbitals centered at the same point:

vi=rniexp(−air)
∇xvi=(nir−ai)Xx−Rxrvi
∇yvi=(nir−ai)Xy−Ryrvi
∇zvi=(nir−ai)Xz−Rzrvi
Δvi=1r2[ni2−2niair+air(air−2)+ni]vi

These expressions are singular at r=0. For r<10−15 the routine returns vi=1 when ni=1 and vi=0 otherwise, with zero gradients and Laplacian.

4. Polynomial part

Going from the atomic basis set to AOs implies a systematic construction of all the angular functions of each shell. We consider two cases for the angular functions: the real-valued spherical harmonics, and the polynomials in Cartesian coordinates. In the case of spherical harmonics, the AOs are ordered in increasing magnetic quantum number (−l≤m≤l), and in the case of polynomials we choose the canonical ordering, i.e

p:px,py,pzd:dxx,dxy,dxz,dyy,dyz,dzzf:fxxx,fxxy,fxxz,fxyy,fxyz,fxzz,fyyy,fyyz,fyzz,fzzzetc.

4.2. General functions for Value, Gradient and Laplacian of a polynomial

A polynomial is centered on a nucleus 𝐑i

Pl(𝐫,𝐑i)=(x−Xi)a(y−Yi)b(z−Zi)c

The gradients with respect to electron coordinates are

∂∂xPl(𝐫,𝐑i)=a(x−Xi)a−1(y−Yi)b(z−Zi)c∂∂yPl(𝐫,𝐑i)=b(x−Xi)a(y−Yi)b−1(z−Zi)c∂∂zPl(𝐫,𝐑i)=c(x−Xi)a(y−Yi)b(z−Zi)c−1

and the Laplacian is

(∂∂x2+∂∂y2+∂∂z2)Pl(𝐫,𝐑i)=a(a−1)(x−Xi)a−2(y−Yi)b(z−Zi)c+b(b−1)(x−Xi)a(y−Yi)b−2(z−Zi)c+c(c−1)(x−Xi)a(y−Yi)b(z−Zi)c−2.

qmckl_ao_polynomial_vgl computes the values, gradients and Laplacians at a given point in space, of all polynomials with an angular momentum up to lmax.
