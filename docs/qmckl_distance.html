Inter-particle distances

1. Introduction

This module computes the distances between the points of two sets, and the quantities derived from them that the wave function needs: the squared distance, the distance, and the rescaled distance Cij=(1−e−κrij)/κ with its gradient and Laplacian.

All four functions take a context, the two transpose flags, the sizes m and n, the arrays and their leading dimensions; the two rescaled ones also take rescale_factor_kappa. With 'N', the three coordinates of a point are consecutive, so A is [m][3] in C and (3,m) in Fortran. With 'T', they are stored by component: [3][m] in C and (m,3) in Fortran. The same rule applies to B with n. The flags are case-insensitive. The context stores its points the transposed way, and that is also the layout these functions are fastest on.

2. Squared distance

2.1. qmckl_distance_sq

qmckl_distance_sq computes the matrix of squared Euclidean distances between the points of two sets. It is the quantity that qmckl_distance returns, without the square root:

Cij=∑k=13(Ak,i−Bk,j)2

where A and B hold the coordinates of the two sets and C is the result.

Variable Type In/Out Description
context qmckl_context in Global state
transa char in Array A is 'N': Normal, 'T': Transposed
transb char in Array B is 'N': Normal, 'T': Transposed
m int64_t in Number of points in the first set
n int64_t in Number of points in the second set
A double[][lda] in Array containing the m×3 matrix A
lda int64_t in Leading dimension of array A
B double[][ldb] in Array containing the n×3 matrix B
ldb int64_t in Leading dimension of array B
C double[n][ldc] out Array containing the m×n matrix C
ldc int64_t in Leading dimension of array C

Requirements:

  • context is not QMCKL_NULL_CONTEXT
  • m > 0
  • n > 0
  • lda >= 3 if transa == 'N'
  • lda >= m if transa == 'T'
  • ldb >= 3 if transb == 'N'
  • ldb >= n if transb == 'T'
  • ldc >= m
  • A is allocated with at least 3×m×8 bytes
  • B is allocated with at least 3×n×8 bytes
  • C is allocated with at least m×n×8 bytes

2.1.1. Performance

This function is more efficient when A and B are transposed.

5. Rescaled Distance Derivatives

5.1. qmckl_distance_rescaled_gl

qmckl_distance_rescaled_gl computes the gradient and the Laplacian of the rescaled distance with respect to the coordinates of the first set. Each pair contributes four numbers, stored contiguously: the three components of the gradient, then the Laplacian. The output is declared double C[n][ldc][4] and indexed as C[j][i][c], where i numbers the points of the first set and j those of the second.

C(rij)=(1−exp(−κrij))/κ

Here the gradient is defined as follows:

∇iC(rij)=(∂C(rij)∂xi,∂C(rij)∂yi,∂C(rij)∂zi)
and the Laplacian is defined as follows:

ΔiC(rij)=∂2C∂xi2+∂2C∂yi2+∂2C∂zi2

Using the above three formulas, the expression for the gradient and Laplacian is:

∂C(rij)∂xi=xi−xjrijexp(−κrij)

ΔiC(rij)=[2rij−κ]exp(−κrij)

The distance is floored at 1.d-20 before the division, so two coincident points give a zero gradient instead of an undefined one.
