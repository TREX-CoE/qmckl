Code examples

1. Introduction

This page collects worked examples: programs that create a context, put points in it and call the kernels. The first two read a wave function from a TREXIO file, evaluate the orbitals on a regular grid and build the overlap matrix in the MO basis, once in C and once in Fortran. A third program evaluates a single atomic orbital on a grid, and the error-handling subroutine it uses is given as well.

2. Overlap matrix in the MO basis

The example computes the overlap matrix in the MO basis on a regular grid:

Sij=∫ϕi(𝐫)ϕj(𝐫)d𝐫≈∑kϕi(𝐫k)ϕj(𝐫k)δ𝐫

The program reads a wave function from a TREXIO file with qmckl_trexio_read, which fills the context with the electrons, the nuclei, the AOs and the MOs. It then takes the number of nuclei, their coordinates and the number of MOs from the context, and builds a regular mesh of 120 x 120 x 120 points around the molecule, 1728000 points in all. The mesh is handed to the context with qmckl_set_point.

The MO values at those points come from qmckl_get_mo_basis_mo_value, which the program times. They form a matrix M whose element M_ki is the value of MO i at point k, and one call to qmckl_dgemm forms the product M M^T, scaled by the volume element dr of the mesh. The program prints the resulting matrix.

2.1. C

This version adds the electron-nucleus cusp fit. The listing is split into blocks and tangled into mo_ortho.c.

The program fetches the nuclear charges, gives a cusp radius to each element, and passes the radii to qmckl_set_mo_basis_r_cusp, so the MO values come from the cusp-corrected kernels described on the MO page. The fit perturbs the orbitals: the overlap matrix is no longer exactly the identity.

The program creates a context and reads into it a TREXIO file for the water molecule. The file name is hard-coded, ..//share/qmckl/test_data/h2o_5z.h5, and the file does not ship with QMCkl; the Fortran version below takes the name on the command line instead.

We impose the electron-nucleus cusp fitting to occur when the electrons are close to the nuclei. The critical distance is 0.5 atomic units for hydrogens and 0.1 for the oxygen. To identify which atom is an oxygen and which are hydrogens, we fetch the nuclear charges from the context.

3. Checking errors

Every QMCkl function returns an exit code, QMCKL_SUCCESS when the call worked. qmckl_check_error stops the program on any other code: it prints the message it is given, prints the text of the code with qmckl_string_of_error, whose buffer holds 128 characters, and exits with the code. The program below calls it after each QMCkl call.

4. Computing an atomic orbital on a grid

The Fortran program ao_grid evaluates one atomic orbital on a regular grid. The grid has point_num_x points along each direction, so it holds point_num points in all, and its box extends five atomic units beyond the molecule. The points are stored as (point_num,3), whose Fortran layout already has all the x coordinates first, so they reach qmckl_set_point with transp='T'.
