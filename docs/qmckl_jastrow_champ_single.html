CHAMP Jastrow Factor Single

1. Introduction

Single-electron-move counterpart of the CHAMP Jastrow factor. A move displaces one electron, so only the distances from that electron to the others change. Instead of recomputing the full Jastrow factor, these routines return the difference

δJ=J(𝐫′,𝐑)−J(𝐫,𝐑)

between the factor at the proposed position 𝐫′ of the moved electron and at its current position 𝐫, together with the same differences for the gradients, the Laplacians and the derivatives with respect to the Jastrow parameters. qmckl_get_jastrow_champ_single_accept adds them to the stored values once the move is accepted.

3. Single point

3.1. Set

We set the coordinates of the num-th electron for all walkers, where num is the electron which has to be moved. The dimension of coord is

  • [walknum][3] if transp is 'N'
  • [3][walknum] if transp is 'T'

Internally, the coordinates are stored in 'N' format as opposed to eleccoord. This function has to be called before any other functions from this module.

The Fortran function shifts the num by 1 because of 1-based indexing.

5. Electron-electron-nucleus Jastrow

Computes the single-electron contributions to the electron-electron-nucleus Jastrow term.

A move displaces one electron, so only the distances between that electron and the others change, and only those rescaled distances are recomputed:

R~iα=e−κlRiαandr~ij=e−κlrij,

for each power l from 0 to cord_num. From these, we can calculate the δR~ and δr~ using

δR~iα=R~iαnew−R~iαoldandδr~ij=r~ijnew−r~ijold.

With these, we can now calculate the single electron contribution to the δP matrix, using the equation

δPi,α,k,l=Pi,α,k,lnew−Pi,α,k,lold=∑j=1Nelec(r~i,j,kδR~j,α,lδj,num+δr~i,j,kR~j,α,l(δj,num+δi,num)+δr~i,j,kδR~j,α,lδj,num)=∑j=1Nelec(δr~i,j,kR~j,α,lδi,num)+r~i,num,kδR~num,α,l+δr~i,num,k(R~num,α,l+δR~num,α,l).

Then, the electron-electron-nucleus Jastrow value can be calculated by

δJeen=Jeennew−Jeenold=∑p=2Nnord∑k=0p−1∑l=0p−k−2δk,0∑α=1Nnuclcl,k,p,α∑i=1Nelec(δR~i,α,(p−k−l)/2Pi,α,k,(p−k+l)/2δi,num+R~i,α,(p−k−l)/2δPi,α,k,(p−k+l)/2+δR~i,α,(p−k−l)/2δPi,α,k,(p−k+l)/2δi,num)=∑p=2Nnord∑k=0p−1∑l=0p−k−2δk,0∑α=1Nnuclcl,k,p,α(∑i=1Nelec(R~i,α,(p−k−l)/2δPi,α,k,(p−k+l)/2)+δR~num,α,(p−k−l)/2(Pnum,α,k,(p−k+l)/2+δPnum,α,k,(p−k+l)/2))

To calculate the gradients and Laplacian of the electron-electron-nucleus Jastrow, we first have to calculate the gradients and Laplacian of the rescaled distances,

∂i,mR~iα=−κle−κlRiαri,m−Rα,mRiαand∂i,4R~iα=−κl(2Riα−κl)e−κlRiα,
where i is the electron of which we are taking the derivative and m=1:3 are the gradients and m=4 is the Laplacian. The derivatives of the single electron rescaled electron-nucleus distances are only nonzero when i=num. Similarly for r we get
∂i,mr~ij=−κle−κlrijri,m−rj,mrijand∂i,4r~ij=−κl(2rij−κl)e−κlrij.

With these, we can now calculate the gradient and Laplacian of the δP matrix, using the equation

∂i,mδPi,α,k,l=∂i,mPi,α,k,lnew−∂i,mPi,α,k,lold=∂i,mδr~num,i,k(∂i,mδR~num,α,l+∂i,mR~num,α,l)gm+∂i,mr~num,i,kδR~num,α,l+δi,num∑j=1Nelec(∂j,mδr~num,j,kR~j,α,l),

where gm={−1,−1,−1,1}.

Then, the gradient and Laplacian of the electron-electron-nucleus Jastrow value can be calculated by

δ∂i,mJeen=∂i,mJeennew−∂i,mJeenold=∑p=2Nnord∑k=0p−1∑l=0p−k−2δk,0∑α=1Nnuclcl,k,p,α(R~i,α,(p−k−l)/2∂i,mδPi,α,k,(p−k+l)/2+R~i,α,(p−k+l)/2∂i,mδPi,α,k,(p−k−l)/2 +∂i,mR~i,α,(p−k−l)/2δPi,α,k,(p−k+l)/2+∂i,mR~i,α,(p−k+l)/2δPi,α,k,(p−k−l)/2 +δi,num(δR~i,α,(p−k−l)/2(∂i,mPi,α,k,(p−k+l)/2+∂i,mδPi,α,k,(p−k+l)/2)+δR~i,α,(p−k+l)/2(∂i,mPi,α,k,(p−k−l)/2+∂i,mδPi,α,k,(p−k−l)/2) +∂i,mδR~i,α,(p−k−l)/2(Pi,α,k,(p−k+l)/2+δPi,α,k,(p−k+l)/2)+∂i,mδR~i,α,(p−k+l)/2(Pi,α,k,(p−k−l)/2+δPi,α,k,(p−k−l)/2)) +δm,4∑d=13(∂i,dR~i,α,(p−k−l)/2∂i,dδPi,α,k,(p−k+l)/2+∂i,dR~i,α,(p−k+l)/2∂i,dδPi,α,k,(p−k−l)/2) +δm,4δi,num∑d=13(∂i,dδR~i,α,(p−k−l)/2(∂i,dPi,α,k,(p−k+l)/2+∂i,dδPi,α,k,(p−k+l)/2)+∂i,dδR~i,α,(p−k+l)/2(∂i,dPi,α,k,(p−k−l)/2+∂i,dδPi,α,k,(p−k−l)/2)))

6. Electron-electron Jastrow

Single-electron-move contribution to the Jee Jastrow factor. As in the three-body case, only the rescaled distances to the moved electron are updated,

r~ij=1−e−κrijκ,
so the value follows directly, without intermediate terms. The b1 term of a pair carries the spin weight wij=12(1+δij↑↓), which is 1 for opposite spins and 1/2 for parallel spins, and which is 1 for every pair when spin_independent is set. With Nbord the degree of the b polynomial, the difference is
δJee=∑i∑j<iδj,num(wijb1r~ijnew1+b2r~ijnew−wijb1r~ijold1+b2r~ijold+∑k=2Nbordbk+1(r~ijnewk−r~ijoldk)),

8. Accept single electron move

This function accepts a proposed single-electron move. It adds the differences computed above to the stored Jastrow factors, gradients and Laplacians, and overwrites the entries of the moved electron in the full distance and rescaled-distance arrays, together with their derivatives. The coordinates of that electron are replaced by the proposed ones, and the dates are updated, so that a Jastrow function called right after the move does not trigger a recomputation.

For instance,

Jen=Jen+δJenJee=Jee+δJeeJeen=Jeen+δJeen∂i,mJen=∂i,mJen+∂i,mδJen∂i,mJee=∂i,mJee+∂i,mδJee∂i,mJeen=∂i,mJeen+∂i,mδJeen
