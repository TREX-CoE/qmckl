  The ultimate goal of the QMCkl library is to provide a high-performance
  implementation of the main kernels of Quantum Monte Carlo (QMC) methods.
  In this particular implementation of the library, we focus on the
  definition of the API and the tests, and on a /pedagogical/ presentation
  of the algorithms: we expect HPC experts to use this repository as a
  reference for re-writing optimized libraries.

  The documentation is split into one page per module, listed below in
  reading order. The [[./qmckl.html][Introduction]] explains how to build the library and
  which conventions the source code follows; each of the following pages
  documents the data structures and the kernels of one module.
