* Introduction

  A context holds the state of a calculation: the molecular system, the
  numerical precision, the points at which the kernels evaluate, the values
  they computed, the error of the last call that failed, the memory the
  context owns, and the number of OpenMP threads to use. All but four public
  functions take a context as their first argument; the exceptions are
  ~qmckl_context_create~, ~qmckl_string_of_error~ and the two
  ~qmckl_test_precision~ helpers.

  This page describes the handle that designates a context, how its validity
  is checked, what the context contains, the OpenMP thread count it carries,
  and its lifetime: creation, locking, copy and destruction.

* Context handling

  The context is the central data structure of QMCkl: it holds the state of
  the calculation and caches the values the library computes. A getter copies
  such a cached array into the buffer the caller provides; the linear-algebra
  kernels, ~qmckl_dgemm~, ~qmckl_dgemv~ and ~qmckl_dger~, take the context only
  to report an argument error, and write straight into the caller's arrays.

  The handle is the address of a private structure, cast to an integer: the
  caller never sees the structure itself, so its layout can change without
  breaking a program.
  
  To simplify compatibility with other languages, Fortran in particular, the
  pointer to the internal data structure is reinterpreted as a 64-bit signed
  integer, and that integer is the ~qmckl_context~ type; a Fortran caller
  declares it ~integer(qmckl_context)~. ~QMCKL_NULL_CONTEXT~, zero, is the
  null handle and designates no context. Most entry points test it and return
  ~QMCKL_INVALID_CONTEXT~; ~qmckl_lock~ and ~qmckl_unlock~ ignore it.

** Design considerations

  An immutable context would have been simpler to reason about, but every
  update would have to return a new one, and freeing what the caller no longer
  uses would need reference counting or a garbage collector. The context is
  mutable instead. It has to be handled with care: initialize it before use,
  synchronize concurrent modifications, and destroy it when it is no longer
  needed.

  Mutable state also avoids copying large arrays on every update: a computed
  quantity is written into the context in place, and the date of the write is
  recorded next to it.

  By convention, in this file ~context~ is a ~qmckl_context~ variable
  and ~ctx~ is a ~qmckl_context_struct*~ pointer.

** Data structure

   The structure holds the state of the library: one sub-structure per model
   (nucleus, electron, atomic orbitals, molecular orbitals, Jastrow factor,
   forces), the points at which the kernels evaluate, the numerical precision,
   the date, the error record, the registry of the memory blocks the context
   owns, the lock, the OpenMP thread count, and a pointer reserved for
   alternative implementations. It is defined in
   ~qmckl_context_private_type.h~, a private header that the installation does
   not ship, so the layout is not part of the API.

   A pointer field added to the context is handled in three places. It is
   zeroed by ~qmckl_context_create~, freed by ~qmckl_context_destroy~, which
   only frees what the memory registry holds and therefore requires the block
   to be allocated with ~qmckl_malloc~, and copied by ~qmckl_context_copy~
   through a ~qmckl_copy_*~ function.

** Extension mechanism
    
   ~qmckl_extra~ is reserved for a variant of the library that needs to hang
   its own data off the context: a GPU implementation could store its device
   identifier, its streams and its device buffers in such a structure. The
   library itself never reads or writes the pointer and offers no accessor, so
   only code that includes the private header can use it. ~qmckl_context_copy~
   copies the pointer without what it points to, and ~qmckl_context_destroy~
   does not free it.
   
** Validity checking

   A tag is written at the head of the structure when the context is created,
   and replaced by another value when it is destroyed, so that a handle to a
   context that no longer exists can be recognized. The check is cheap and
   catches the common mistakes only: the tag is read through the handle, so a
   handle that points nowhere crashes the program instead of returning an
   error, and reading the tag of a destroyed context reads freed memory, which
   usually still holds the invalid tag but may hold anything if the block has
   been reused.

   #+begin_src c :comments org :tangle (eval h_private_type) :noweb yes :exports none
#define VALID_TAG   0xBEEFFACE
#define INVALID_TAG 0xDEADBEEF
   #+end_src

   ~qmckl_context_check~ performs that check and gives the handle back
   unchanged when the tag is ~VALID_TAG~, or ~QMCKL_NULL_CONTEXT~ otherwise.
   Most entry points call it before they use the handle, and return
   ~QMCKL_INVALID_CONTEXT~ when it fails. ~qmckl_lock~ and ~qmckl_unlock~ are
   the exception: they only compare the handle with ~QMCKL_NULL_CONTEXT~.

   #+begin_src c :tangle (eval c) :exports none
qmckl_context qmckl_context_check(const qmckl_context context) {

  if (context == QMCKL_NULL_CONTEXT)
    return QMCKL_NULL_CONTEXT;

  const qmckl_context_struct* const ctx = (qmckl_context_struct*) context;

  /* Try to access memory */
  if (ctx->tag != VALID_TAG) {
      return QMCKL_NULL_CONTEXT;
  }

  return context;
}
   #+end_src

** Cache invalidation

   The context keeps a date, a ~uint64_t~ that starts at zero and only grows.
   Every cached array is stored with the date of its computation, and a
   provider recomputes it when the clock it watches is more recent than that
   date: ~ctx->date~ for the arrays that depend on the parameters,
   ~ctx->point.date~ for the ones that depend on the coordinates, and
   ~ctx->single_point.date~ on the single-point path.

   ~qmckl_context_touch~ increments ~ctx->date~ and copies it into
   ~ctx->point.date~ and ~ctx->electron.walker.point.date~, so everything
   computed before the touch is stale. ~qmckl_set_point~ ends with a touch,
   since moving the points is what makes the cached distances wrong.

   When the electron coordinates have changed, the context is touched
   using the following function.

   #+begin_src c :comments org :tangle (eval h_func)
qmckl_exit_code
qmckl_context_touch (const qmckl_context context);
   #+end_src

   It does not take the lock, and it recomputes nothing: the values are
   recomputed lazily, in the providers.

   #+begin_src c :tangle (eval c) :exports none
qmckl_exit_code
qmckl_context_touch(const qmckl_context context)
{

  if (qmckl_context_check(context) == QMCKL_NULL_CONTEXT) {
    return qmckl_failwith( context,
                           QMCKL_INVALID_CONTEXT,
                           "qmckl_context_touch",
                           NULL);
  }

  qmckl_context_struct* const ctx = (qmckl_context_struct*) context;

  ctx->date += 1UL;
  ctx->point.date = ctx-> date;
  ctx->electron.walker.point.date = ctx-> date;
  return QMCKL_SUCCESS;
}

** Creation

   To create a new context, ~qmckl_context_create()~ is used.
   - It returns a handle, or ~QMCKL_NULL_CONTEXT~ when one of the two
     allocations fails: the structure itself, and the initial registry of 128
     memory blocks.
   - The structure is zeroed first, then given its tag and its lock (recursive
     where ~PTHREAD_MUTEX_RECURSIVE~ exists), the default precision of 53 bits
     with range 11, and the thread count.
   - Each subsystem is then reset by its ~qmckl_init_*~ function: the point,
     the electron, the nucleus, the atomic basis, the molecular basis and the
     Jastrow factor. Creation leaves the atomic basis cartesian and the
     Jastrow parameters at -1 until the user sets them.

   #+end_src

   #+begin_src c :tangle (eval c) :exports none
qmckl_context qmckl_context_create() {

  qmckl_context_struct* const ctx =
    (qmckl_context_struct*) malloc (sizeof(qmckl_context_struct));

  if (ctx == NULL) {
    return QMCKL_NULL_CONTEXT;
  }

  /* Set all pointers and values to NULL */
  {
    memset(ctx, 0, sizeof(qmckl_context_struct));
  }

  /* Initialize lock */
  {
    pthread_mutexattr_t attr;
    int rc;

    rc = pthread_mutexattr_init(&attr);
    assert (rc == 0);

#ifdef PTHREAD_MUTEX_RECURSIVE
    (void) pthread_mutexattr_settype(&attr, PTHREAD_MUTEX_RECURSIVE);
#endif

    rc = pthread_mutex_init ( &(ctx->mutex), &attr);
    assert (rc == 0);

    (void) pthread_mutexattr_destroy(&attr);
  }

  /* Initialize data */
  {
    ctx->tag = VALID_TAG;

    const qmckl_context context = (qmckl_context) ctx;
    assert ( qmckl_context_check(context) != QMCKL_NULL_CONTEXT );

    qmckl_exit_code rc;

    ctx->numprec.precision = QMCKL_DEFAULT_PRECISION;
    ctx->numprec.range = QMCKL_DEFAULT_RANGE;

#ifdef HAVE_OPENMP
    ctx->num_threads = omp_get_max_threads();
#else
    ctx->num_threads = 1;
#endif

    rc = qmckl_init_point(context);
    assert (rc == QMCKL_SUCCESS);

    rc = qmckl_init_electron(context);
    assert (rc == QMCKL_SUCCESS);

    rc = qmckl_init_nucleus(context);
    assert (rc == QMCKL_SUCCESS);

    rc = qmckl_init_ao_basis(context);
    assert (rc == QMCKL_SUCCESS);

    rc = qmckl_init_mo_basis(context);
    assert (rc == QMCKL_SUCCESS);

    /*
    rc = qmckl_init_determinant(context);
    assert (rc == QMCKL_SUCCESS);
    */

    rc = qmckl_init_jastrow_champ(context);
    assert (rc == QMCKL_SUCCESS);
  }

  /* Allocate qmckl_memory_struct */
  {
    const size_t size = 128L;
    qmckl_memory_info_struct * new_array = calloc(size, sizeof(qmckl_memory_info_struct));
    if (new_array == NULL) {
      free(ctx);
      return QMCKL_NULL_CONTEXT;
    }
    memset( &(new_array[0]), 0, size * sizeof(qmckl_memory_info_struct) );

    ctx->memory.element = new_array;
    ctx->memory.array_size = size;
    ctx->memory.n_allocated = (size_t) 0;
  }

  return (qmckl_context) ctx;
}

** Locking

   For thread safety, a context can be locked and unlocked. Each context has
   one mutex, initialized as recursive where ~PTHREAD_MUTEX_RECURSIVE~ is
   available, and ~lock_count~ counts the lock calls not yet matched by an
   unlock. Both functions return ~void~: they ignore a ~QMCKL_NULL_CONTEXT~
   handle, print to ~stderr~ and assert if pthread reports an error, and skip
   the tag check, so a stale handle is not rejected here.

   # Header
   #+begin_src c :comments org :tangle (eval h_func)
void qmckl_lock  (qmckl_context context);
void qmckl_unlock(qmckl_context context);
   #+end_src

   # Source
   #+begin_src c :tangle (eval c) :exports none
void qmckl_lock(qmckl_context context) {
  if (context == QMCKL_NULL_CONTEXT)
    return ;
  qmckl_context_struct* const ctx = (qmckl_context_struct*) context;
  errno = 0;
  int rc = pthread_mutex_lock( &(ctx->mutex) );
  if (rc != 0) {
    fprintf(stderr, "DEBUG qmckl_lock:%s\n", strerror(rc) );
    fflush(stderr);
  }
  assert (rc == 0);
  ctx->lock_count += 1;
}

void qmckl_unlock(const qmckl_context context) {
  if (context == QMCKL_NULL_CONTEXT)
    return ;
  qmckl_context_struct* const ctx = (qmckl_context_struct*) context;
  int rc = pthread_mutex_unlock( &(ctx->mutex) );
  if (rc != 0) {
    fprintf(stderr, "DEBUG qmckl_unlock:%s\n", strerror(rc) );
    fflush(stderr);
  }
  assert (rc == 0);
  ctx->lock_count -= 1;
}
   #+end_src

** Copy

   ~qmckl_context_copy~ makes a deep copy of a context. The new context has
   its own mutex and its own memory registry, the scalar fields are copied by
   value (~date~, the numerical precision, the error record, the thread
   count), each subsystem is copied by its ~qmckl_copy_*~ function, and
   ~qmckl_extra~ is copied as a pointer. The source stays locked for the whole
   copy. The function returns ~QMCKL_NULL_CONTEXT~ when the source is invalid
   or when a sub-copy fails, in which case it destroys the context it had
   begun to build.

   # Header
   #+begin_src c :comments org :tangle (eval h_func)
qmckl_context qmckl_context_copy(const qmckl_context context);
   #+end_src


   # Source
   #+begin_src c :tangle (eval c) :exports none
qmckl_context qmckl_context_copy(const qmckl_context context) {
  qmckl_exit_code rc;

  const qmckl_context checked_context = qmckl_context_check(context);

  if (checked_context == QMCKL_NULL_CONTEXT) {
    return QMCKL_NULL_CONTEXT;
  }

  qmckl_lock(context);
  {

    const qmckl_context_struct* const old_ctx =
      (qmckl_context_struct*) checked_context;

    /* Create a new context using the standard creation function */
    qmckl_context new_context = qmckl_context_create();
    if (new_context == QMCKL_NULL_CONTEXT) {
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    qmckl_context_struct* const new_ctx =
      (qmckl_context_struct*) new_context;

    /* Copy scalar values and structs that don't contain pointers */
    new_ctx->date = old_ctx->date;
    new_ctx->numprec = old_ctx->numprec;
    new_ctx->error = old_ctx->error;
    new_ctx->num_threads = old_ctx->num_threads;

    /* Deep copy point structure using dedicated function */
    rc = qmckl_copy_point(new_context, &(old_ctx->point), &(new_ctx->point));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Deep copy single_point structure using dedicated function */
    rc = qmckl_copy_jastrow_champ_single(new_context, &(old_ctx->single_point), &(new_ctx->single_point));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Deep copy nucleus structure using dedicated function */
    rc = qmckl_copy_nucleus(new_context, &(old_ctx->nucleus), &(new_ctx->nucleus));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Deep copy electron structure using dedicated function */
    rc = qmckl_copy_electron(new_context, &(old_ctx->electron), &(new_ctx->electron));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Deep copy ao_basis structure using dedicated function */
    rc = qmckl_copy_ao_basis(new_context, &(old_ctx->ao_basis), &(new_ctx->ao_basis));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Deep copy mo_basis structure using dedicated function */
    rc = qmckl_copy_mo_basis(new_context, &(old_ctx->mo_basis), &(new_ctx->mo_basis));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Deep copy jastrow_champ structure using dedicated function */
    rc = qmckl_copy_jastrow_champ(new_context, &(old_ctx->jastrow_champ), &(new_ctx->jastrow_champ));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Deep copy forces structure using dedicated function */
    rc = qmckl_copy_forces(new_context, &(old_ctx->forces), &(new_ctx->forces));
    if (rc != QMCKL_SUCCESS) {
      qmckl_context_destroy(new_context);
      qmckl_unlock(context);
      return QMCKL_NULL_CONTEXT;
    }

    /* Copy qmckl_extra pointer (shallow copy - implementation specific) */
    new_ctx->qmckl_extra = old_ctx->qmckl_extra;

    qmckl_unlock(context);
    return new_context;
  }
}

** OpenMP thread count

   The ~num_threads~ field is the thread count the parallel regions use: the
   kernels that use it spell ~num_threads(ctx->num_threads)~ on their pragma,
   inside ~#ifdef HAVE_OPENMP~. In a build without OpenMP the field is read and
   written but never used. It starts at ~omp_get_max_threads()~, or at 1 when
   OpenMP is unavailable.

   ~qmckl_context_get_num_threads~ copies the field into a variable of the
   caller. A ~NULL~ variable gives ~QMCKL_INVALID_ARG_2~, and an invalid
   context gives ~QMCKL_INVALID_CONTEXT~.
   
   # Header
   #+begin_src c :comments org :tangle (eval h_func)
qmckl_exit_code qmckl_context_get_num_threads(const qmckl_context context, int32_t* const num_threads);
   #+end_src

   # Source
   #+begin_src c :tangle (eval c) :exports none
qmckl_exit_code qmckl_context_get_num_threads(const qmckl_context context, int32_t* const num_threads) {
  if (qmckl_context_check(context) == QMCKL_NULL_CONTEXT)
    return QMCKL_INVALID_CONTEXT;

  if (num_threads == NULL) {
    return qmckl_failwith(context,
                          QMCKL_INVALID_ARG_2,
                          "qmckl_context_get_num_threads",
                          "num_threads is a null pointer");
  }

  const qmckl_context_struct* const ctx = (qmckl_context_struct*) context;
  *num_threads = ctx->num_threads;
  return QMCKL_SUCCESS;
}

qmckl_exit_code qmckl_context_set_num_threads(const qmckl_context context, const int32_t num_threads) {
  if (qmckl_context_check(context) == QMCKL_NULL_CONTEXT)
    return QMCKL_INVALID_CONTEXT;

  if (num_threads <= 0) {
    return qmckl_failwith(context,
                          QMCKL_INVALID_ARG_2,
                          "qmckl_context_set_num_threads",
                          "num_threads must be positive");
  }

  qmckl_context_struct* const ctx = (qmckl_context_struct*) context;
  assert (ctx != NULL);

  qmckl_lock(context);
  {
    ctx->num_threads = num_threads;
  }
  qmckl_unlock(context);

  return QMCKL_SUCCESS;
}

qmckl_exit_code qmckl_context_unset_num_threads(const qmckl_context context) {
  if (qmckl_context_check(context) == QMCKL_NULL_CONTEXT)
    return QMCKL_INVALID_CONTEXT;

  qmckl_context_struct* const ctx = (qmckl_context_struct*) context;
  assert (ctx != NULL);

  qmckl_lock(context);
  {
#ifdef HAVE_OPENMP
    ctx->num_threads = omp_get_max_threads();
#else
    ctx->num_threads = 1;
#endif
  }
  qmckl_unlock(context);

  return QMCKL_SUCCESS;
}

** Destroy

   ~qmckl_context_destroy~ frees every block still registered in the context,
   then the registry array, then marks the tag invalid, destroys the mutex and
   frees the structure. It returns ~QMCKL_INVALID_CONTEXT~ for a handle that is
   not a valid context, and ~QMCKL_SUCCESS~ otherwise. The handle is not valid
   afterwards. A block that was not allocated through ~qmckl_malloc~ is not in
   the registry, and nothing frees it here.

    # Source
    #+begin_src c :tangle (eval c) :exports none
qmckl_exit_code
qmckl_context_destroy (const qmckl_context context)
{

  const qmckl_context checked_context = qmckl_context_check(context);
  if (checked_context == QMCKL_NULL_CONTEXT) return QMCKL_INVALID_CONTEXT;

  qmckl_context_struct* const ctx = (qmckl_context_struct*) context;
  assert (ctx != NULL);  /* Shouldn't be possible because the context is valid */

  qmckl_lock(context);
  {
    /* Memory: Remove all allocated data */
    for (size_t pos = (size_t) 0 ; pos < ctx->memory.array_size ; ++pos) {
      if (ctx->memory.element[pos].pointer != NULL) {
        free(ctx->memory.element[pos].pointer);
        memset( &(ctx->memory.element[pos]), 0, sizeof(qmckl_memory_info_struct) );
        ctx->memory.n_allocated -= 1;
      }
    }
    assert (ctx->memory.n_allocated == (size_t) 0);
    free(ctx->memory.element);
    ctx->memory.element = NULL;
    ctx->memory.array_size = (size_t) 0;
  }
  qmckl_unlock(context);

  ctx->tag = INVALID_TAG;

  const int rc_destroy = pthread_mutex_destroy( &(ctx->mutex) );
  if (rc_destroy != 0) {
/* DEBUG */
     fprintf(stderr, "qmckl_context_destroy: %s (count = %d)\n", strerror(rc_destroy), ctx->lock_count);
     abort();
  }

  free(ctx);

  return QMCKL_SUCCESS;
}
